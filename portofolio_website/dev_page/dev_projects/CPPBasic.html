Process

Lesson 1: I made an item class that included a variable for a name, weapon type and price. Then i called the variable in the main and let it write in the console

Lesson 2: We had to make a function to add an item in the main and add it to a list. Then in the main we let the list write itself in console

Lesson 3: Another class to show the inventory and to add items to a list outside of main, we also had to have a remove function.

Lesson 4: We made a function to add items in the console.

Lesson 5: Making it work endlessly by adding a while loop in the main

Lesson 6: Now we seperated the menu so that the main only had to call the inventoryMenu class
